# NLP coursework

The datasets in `data/` and trained model files in `models/` are not included
in this repository. The model weight files are each larger than GitHub's
100 MB per-file limit, and the datasets and model artifacts are excluded to
keep the repository lightweight. Some notebooks expect these files to be
available locally. Best practice is to run the notebooks in Google Colab and
obtain or generate the required artifacts there before running them.
